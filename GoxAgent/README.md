# GoxAgent

GoxAgent is the local agent component of the GoPrinx ecosystem. It runs on the customer's local network to discover, monitor, and interact with printers (Ricoh, Toshiba) and reports data back to the central server.

## Features
- Network Printer Discovery
- Counter Collection (Ricoh & Toshiba)
- Address Book / Scan-to-Folder Management
- Zero-Fallback Strict Execution Model (See `AGENT.md` for details)
