🔔 CRM Real-time Event Webhook

Fire-and-Forget Architecture (0 Latency Overhead)

GoPrinx pushes real-time HTTP POST notifications directly to your CRM webhook listener whenever any printer's counter meters or hardware status change.

⚡ Trigger Condition
Fired automatically when Agent polling detects a change in counter (total, copier, print, scan) or status (toner, paper, cover, alerts).
🚀 Dispatch Mechanism
Dispatched asynchronously in a background thread pool (10 workers) with a 2.0-second timeout. If CRM is down, data drops cleanly without stalling or queueing.

1. Webhook Destination Configuration

Configure where GoPrinx sends webhook events. You can manage this in System Settings (/configs) or via API:

GET /webhook/infor  →  Read current Webhook URL
POST /webhook/infor  →  Set Webhook URL: {"url": "https://your-crm.com/webhook/infor"}

2. Webhook Event Payload Specification

3. CRM Receiver Guidelines (/webhook/infor)

  • Endpoint URL: /webhook/infor (ví dụ: https://your-crm.com/webhook/infor)
  • HTTP Method: POST
  • Header: Content-Type: application/json, User-Agent: Goxprint-Webhook/1.0
  • Expected Response: Return HTTP 200 OK immediately. Defer heavy CRM database updates or email triggers to background queues.
  • Timeout: 2.0 seconds. Requests taking longer than 2s are aborted and dropped.

4. Sample CRM Receiver Handlers (/webhook/infor)

Node.js / Express: 
app.post('/webhook/infor', (req, res) => {
  const { event, mac_id, counter, status } = req.body;
  console.log(`Received ${event} for MAC ${mac_id}. Total: ${counter?.total}`);
  res.status(200).json({ ok: true });
});
Python / FastAPI: 
@app.post("/webhook/infor")
async def receive_webhook(payload: dict):
    mac = payload.get("mac_id")
    total = payload.get("counter", {}).get("total")
    print(f"Update for {mac}: {total} pages")
    return {"ok": True}
PHP (/webhook/infor): 
<?php
// Endpoint: /webhook/infor
$payload = json_decode(file_get_contents('php://input'), true);
$mac = $payload['mac_id'] ?? '';
$total = $payload['counter']['total'] ?? 0;
// Process update in background/db
http_response_code(200);
echo json_encode(['ok' => true]);
